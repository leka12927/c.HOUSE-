An AI skill that provides design intelligence for building professional UI/UX across multiple platforms and frameworks.

## Features

- **67 UI Styles** - Glassmorphism, Claymorphism, Minimalism, Brutalism, Neumorphism, and more
- **161 Color Palettes** - Industry-specific palettes aligned with 161 product types
- **57 Font Pairings** - Curated typography combinations with Google Fonts imports
- **25 Chart Types** - Recommendations for dashboards and analytics
- **15 Tech Stacks** - React, Next.js, Astro, Vue, Svelte, SwiftUI, Flutter, and more
- **99 UX Guidelines** - Best practices, anti-patterns, and accessibility rules
- **161 Reasoning Rules** - Industry-specific design system generation

## Installation

```bash
npm install -g uipro-cli
uipro init --ai claude
```

## Usage

```bash
python3 .claude/skills/ui-ux-pro-max/scripts/search.py "beauty spa wellness" --design-system -p "Serenity Spa"
```
