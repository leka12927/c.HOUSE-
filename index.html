📚 Guide du débutant

Vous découvrez la gestion de budget ? Voici les bases expliquées simplement, adaptées à votre situation : ménage, commerce physique ou e-commerce.

⬇️ Télécharger le modèle Excel / Google Sheets

💡 Le fichier .xlsx s'ouvre directement dans Excel, ou dans Google Sheets via Fichier → Importer. Il contient un onglet Guide et un onglet par contexte (Ménage, Commerce physique, E-commerce) avec des totaux calculés automatiquement.

🔤 Le vocabulaire de base

Recette / Revenu
Argent qui entre : salaire, vente, remboursement, paiement d'un client.
Dépense
Argent qui sort : loyer, courses, achat de stock, facture, abonnement.
Solde
Ce qu'il vous reste : Solde = total des recettes − total des dépenses.
Charges fixes
Dépenses qui reviennent chaque mois et qu'on ne peut pas éviter facilement (loyer, électricité, abonnements, salaires).
Trésorerie
L'argent immédiatement disponible (en caisse ou sur le compte) pour faire face aux dépenses.
Objectif d'épargne / de chiffre d'affaires
Le montant que vous visez à atteindre sur une période donnée.

🏠 Pour le ménage

  1. Notez tout : chaque salaire, chaque achat, même petit. Utilisez le bouton "+ Ajouter une opération".
  2. Séparez fixe et variable : le loyer ou les abonnements ne changent pas, mais les courses ou les loisirs varient — surveillez surtout ces derniers.
  3. Règle simple (50/30/20) : 50% du revenu pour les besoins essentiels, 30% pour les envies, 20% pour l'épargne.
  4. Vérifiez le solde chaque semaine pour éviter les découverts en fin de mois.

🏪 Pour un commerce physique

  1. Distinguez ventes et achats de stock : une vente est une recette, un réapprovisionnement est une dépense.
  2. Suivez votre trésorerie au quotidien : c'est l'argent qui vous permet de payer fournisseurs et salaires à temps.
  3. Calculez votre marge : Marge = Prix de vente − Coût d'achat. Une marge trop faible met le commerce en danger.
  4. Anticipez les charges fixes (loyer du local, salaires, assurances) : elles tombent même si les ventes baissent.

🛒 Pour l'e-commerce

  1. Comptez tous les frais liés à une vente : commission de la plateforme, frais de paiement, livraison, publicité — pas seulement le prix payé par le client.
  2. Surveillez le coût d'acquisition client : combien dépensez-vous en publicité pour obtenir une commande ?
  3. Gérez les frais fixes mensuels : hébergement, abonnements aux outils, logiciel de comptabilité.
  4. Gardez un œil sur les remboursements et litiges : ils réduisent vos recettes réelles.

🧭 Comment utiliser ce tableau de bord

  • 1. Choisissez votre onglet en haut : Ménage, Commerce physique ou E-commerce. Chaque onglet garde ses propres données.
  • 2. Ajoutez vos opérations avec le bouton "+ Ajouter une opération" ou les boutons Recette ↑ / Dépense ↓.
  • 3. Lisez le graphique "Revenus / Dépenses" pour repérer les mois forts et les mois faibles.
  • 4. Surveillez le solde et les charges fixes pour savoir combien il vous reste réellement à dépenser.
  • 5. Exportez vos données régulièrement (icône ⬇️) pour garder une sauvegarde, par exemple avant de réinitialiser.

💡 Astuce : prenez l'habitude d'enregistrer une opération le jour même. C'est la meilleure façon de garder un suivi fiable, sans effort de mémoire en fin de mois.
